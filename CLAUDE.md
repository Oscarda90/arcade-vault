## Project

The README states the project follows Spec Driven Design via the `/spec` and `/spec-impl` skills from [Klerith/fernando-skills](https://github.com/Klerith/fernando-skills) (`npx skills@latest add Klerith/fernando-skills`). Those skills are **not** currently installed — if a task implies spec-driven work, check whether they are available before assuming.

## Stack / architecture notes

- **Next.js 16.4.5 + React 19.3, App Router**, TypeScript strict. This Next major has breaking changes relative to common training data: consult `node_modules/next/dist/docs/` (notably `01-app/`) before writing framework code. `AGENTS.md` carries this same rule and is regenerated by `next dev` — commit its changes alongside your work rather than reverting them.
- **`next.config.ts` opts into pre-stable features**: `cacheComponents`, `partialPrefetching`, `experimental.agentFeedback`. These change caching/prefetch semantics — read the corresponding docs before adding data fetching or route segments.
- **Tailwind CSS v4**, configured with no `tailwind.config` — theme tokens live in `app/globals.css` via `@import "tailwindcss"` + `@theme inline`. Add design tokens there, not in a JS config. CSS is processed through `@tailwindcss/turbopack`, wired as a Turbopack loader rule in `next.config.ts`.
- Route types come from Next's generated `.next/types` (e.g. `LayoutProps<"/">` in `app/layout.tsx` is global, not imported) — these regenerate on `dev`/`build`, so type errors on a fresh clone usually mean a build hasn't run yet.
- Import alias: `@/*` → repo root.
